# 背景画像のプロンプト（ChatGPT Image 2.5 用）

縦長（9:19.5、スマホ全面）。1枚ずつ、3〜5案を出して選ぶ。保存先は `img/bg.jpg`（幅1170px前後、400KB以下）。

## 案の共通プロンプト

実写の質感の、縦長のスマートフォン用の壁紙。静かな夜。薄い雲でかすんだ満月が画面の上部右寄りにある。
左上から細い桜の枝が静かに伸び、花は少なく、散りかけで、花びらが数枚だけ宙に舞っている。
侘び寂びの趣。余白を大きく取り、色は低彩度。墨のような濃紺と黒、月光のかすかな淡い金、花びらは灰がかった桜色。
画面の下半分は暗く何もなく、文字やボタンを重ねても読める。人物・文字・ロゴ・鳥居・建物は入れない。写真のようにリアルに。

## 変える点（案ごと）
1. 月を大きく、雲を多めに
2. 枝を画面の左上に大きく、月は小さく
3. 水面に月の光がかすかに映る
4. 古い枝（枯れた幹）を主役に、花は2〜3輪だけ
5. 霧が低く漂う

## 組み込み
`img/bg.jpg` を置くだけ。花びらの動きは `js/bg.js` が重ねる。
